# 車城藥局教育平台設計系統

## 品牌方向

此平台是為藥師與藥助設計的醫藥教育工作空間。介面應傳達專業、清晰、冷靜與可追溯性；資訊層級優先於裝飾，讓使用者能快速定位課程、關鍵警示與參考資料。

- **設計語調**：臨床清晰、可信賴、溫和支持。
- **視覺風格**：乾淨的編輯式內容版面，結合細緻卡片與低對比的暖色背景。
- **動態原則**：只用短暫的狀態回饋與焦點轉換；尊重減少動態偏好。
- **避免**：霓虹色、紫粉漸層、過度擬物、純裝飾性圖示、用顏色作為唯一狀態訊號。

## 元件規格

### 導覽

- 桌面版採頂端品牌列與左側章節導覽；行動版保留明確的漢堡選單與搜尋入口。
- 導覽項目以文字和 Material 圖示組合，不使用 emoji。
- 目前頁面以 3px 左側色條與高對比背景標記，不能只依賴顏色。

### 課程卡

- 顯示分類、難度、預估時間、課程標題、說明與進度。
- 卡片整體可點選，但仍保留清楚的「開始學習」連結文字。
- Hover 只微幅提升陰影與邊線；鍵盤 focus 必須有明顯外框。

### 內容狀態 Badge

- `draft`、`review`、`approved`、`published`、`archived` 必須同時使用文字與色彩。
- Badge 應自動換行，不截斷中文標籤。

### 臨床提示區塊

- 分為「重點提醒」、「注意事項」、「高風險／請轉介」三種語意類型。
- 每種提示均有文字標題與對比足夠的底色／邊線；不以紅色本身傳達危險。

### 資訊表格與參考文獻

- 表格在窄螢幕可橫向捲動，並保留欄位標題。
- 參考文獻採編號清單，外部連結附可見的外開提示與來源名稱。

## 頁面規格

### 首頁

1. 平台主張與全站搜尋。
2. 依角色設計的快速入口：課程、疾病、藥物、工具與更新。
3. 「持續學習」課程卡。
4. 最新審查／更新內容。
5. 衛教用途與非個人診療聲明。

### 課程列表與課程首頁

- 用篩選 chip 顯示主題、難度與受眾；所有篩選可用鍵盤操作。
- 課程首頁使用「課程概覽 + 單元清單 + 學習提醒」三欄資訊，窄螢幕改為單欄。

### 文章頁

- 頂部呈現分類、標籤、最後更新／審查日期。
- 右側提供章節目錄與「本頁重點」，行動版收合為可展開區塊。
- 文章結尾依序呈現相關內容、參考資料與更新紀錄。

## 響應式與無障礙標準

- 優先以 375px、768px、1024px、1440px 四個寬度檢查版面。
- 正文與互動元件符合至少 4.5:1 對比；可點按目標至少 44×44px。
- 所有互動皆可使用鍵盤完成，焦點不被固定導覽遮住。
- 不以 hover 作為唯一資訊來源；所有動態均支援 `prefers-reduced-motion`。
- 圖片提供有意義的替代文字；純裝飾圖示標記為隱藏於輔助技術。

## MkDocs Material 落地方式

- 將 `docs/stylesheets/checheng.css` 設為額外樣式表。
- 使用 Material 的 palette、primary／accent token 與 admonition 系統，不在單一頁面寫入顏色常數。
- 以 `overrides/` 建立首頁與共用 partial，讓卡片、提示區塊與 metadata 保持一致。
- 選用 Material Symbols Rounded 作為圖示來源，並為圖示按鈕補上可見或程式化名稱。
