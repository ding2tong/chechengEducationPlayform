# 05｜居家量測

## 本頁重點

- 正確的設備、姿勢與紀錄方式會影響讀值的參考價值。
- 重要的是建立可供專業人員判讀的趨勢，而非追逐單一數字。

## 衛教步驟

1. 確認使用合適且狀況良好的量測設備。
2. 在固定、安靜且可重複的條件下量測。
3. 記錄日期、時間、讀值與可能影響因素。
4. 依醫療團隊建議攜帶紀錄回診或諮詢。

!!! warning "設備與操作問題"
    若袖帶尺寸不合、設備異常或量測結果反覆差異大，請協助民眾確認設備使用方式，必要時請藥師或醫療人員評估。
