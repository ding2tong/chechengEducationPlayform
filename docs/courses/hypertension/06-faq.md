# 06｜常見問答

## 血壓一次偏高，就是高血壓嗎？

不一定。血壓數值會受量測條件與當下狀態影響；應以正確方式進行規律量測，並由醫療專業人員綜合判讀。

## 血壓正常後可以自行停藥嗎？

不應自行停藥或調整劑量。血壓控制穩定可能與既有治療有關，任何調整都應先與處方醫師或藥師討論。

## 量血壓前要注意什麼？

請依設備說明與醫療團隊的指示，維持相對固定且安靜的量測條件，並記錄結果供後續討論。

!!! danger "何時應立即求助？"
    若出現急性胸痛、呼吸困難、明顯神經學症狀、意識改變或其他嚴重不適，應立即依緊急處置流程求助。
