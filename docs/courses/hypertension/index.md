# 高血壓完整課程

建立第一線可用的高血壓衛教與用藥溝通基礎。

<div class="cc-meta-row" markdown>

<span>入門</span><span>6 個單元</span><span>約 45 分鐘</span>

</div>

## 你將學會

- 以正確方式理解血壓數值與常見風險。
- 區分一般衛教與需要進一步處理的情境。
- 協助民眾建立居家量測與生活型態管理的習慣。
- 掌握常見降血壓藥的衛教溝通重點。

!!! warning "使用前提醒"
    本課程是教育訓練起點。涉及症狀惡化、懷孕、腎功能、交互作用或調藥問題時，請依現場流程轉由藥師或醫療團隊評估。
