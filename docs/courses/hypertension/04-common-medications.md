# 04｜常用藥物

## 本頁重點

- 用藥衛教以規律服用、正確追蹤與辨識需諮詢情境為核心。
- 藥物選擇與調整需由處方與醫療團隊決定。

## 第一線衛教重點

可確認民眾是否理解服用時間、是否有漏服、是否同時使用其他處方藥、成藥或保健食品。對於副作用、交互作用、懷孕／備孕、腎肝功能與自行停藥疑慮，應交由藥師進一步評估。

!!! info "溝通原則"
    先理解民眾的實際困難，再協助轉介。避免以固定答案替代個別病人的處方判斷。
